A Home, localizada no arquivo home.html, foi desenvolvida utilizando CSS Grid, garantindo uma organização estruturada dos elementos por meio de linhas, colunas e áreas bem definidas. Já a index.html foi construída com Flexbox, priorizando um alinhamento simples e responsivo dos conteúdos em uma única dimensão.

O CSS Grid é voltado para layouts bidimensionais, permitindo controlar linhas e colunas ao mesmo tempo, sendo ideal para estruturar páginas completas. O Flexbox trabalha de forma unidimensional, organizando os elementos em linha ou coluna, sendo mais indicado para alinhar e distribuir componentes dentro de uma seção.
