A Home, localizada no arquivo home.html, foi desenvolvida utilizando Flexbox, garantindo uma organização estruturada dos elementos por meio de alinhamento, direção e distribuição dos conteúdos. Já a index.html também foi construída com Flexbox, priorizando um alinhamento simples e responsivo dos conteúdos em uma única dimensão.

O Flexbox é voltado para layouts unidimensionais, permitindo organizar os elementos em linha ou coluna, sendo ideal para alinhar e distribuir componentes dentro de uma seção. Seu funcionamento facilita a criação de layouts responsivos, controlando o posicionamento, o espaçamento e o alinhamento dos elementos de forma simples e flexível.
